## 4. GitHub sin plan de pago

En repos **públicos** los runners estándar de Actions y Pages son gratuitos; aun así lo usamos con cabeza:
- CI con `concurrency` (cancela ejecuciones obsoletas), `paths-ignore` para docs/specs, timeouts cortos, caché de npm,
  E2E solo en chromium y artefactos con retención de 3 días.
- Dependabot mensual y agrupado (máx. 3 PRs). Activa en *Settings → Code security*: Dependabot alerts, secret
  scanning y push protection (gratuitos en repos públicos; comprueba el estado actual en GitHub).
- Issues con plantillas (historia / bug) como backlog; un **GitHub Project** (tablero) opcional para la defensa.
- PR por change con plantilla = Definition of Done. Protección de `main`: exigir PR y el check `quality`.
  Ojo: los PR que solo tocan docs no disparan CI por `paths-ignore`; si marcas el check como obligatorio, quita
  `paths-ignore` de `pull_request` o permite merge sin él en esos casos.
